# sql-estudos

Registro dos meus estudos de SQL, organizado por tema. Cada pasta traz
consultas escritas por mim, com a pergunta, o raciocínio e o tema praticado.

**Banco usado:** SQLite (DBeaver) | **Em andamento:** sim, atualizado a cada módulo

## Temas

| Pasta | O que pratiquei |
|---|---|
| [01_basico](01_basico) | Agrupamentos, operadores de comparação, lógicos e de intervalo, CASE |
| [02_joins](02_joins) | INNER JOIN, LEFT JOIN, montagem de grande tabela |
| [03_subqueries](03_subqueries) | Subqueries no SELECT, WHERE e FROM |
| [04_colunas_e_funcoes](04_colunas_e_funcoes) | Novas colunas, operações e funções de coluna |
| [05_window_functions](05_window_functions) | Funções de janela |
| [06_cte_with](06_cte_with) | Subqueries com WITH |
| [07_ddl_dml](07_ddl_dml) | CREATE, INSERT, DELETE e ALTER |
