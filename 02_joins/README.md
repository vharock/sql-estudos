
# JOINs

## Objetivo
Praticar a combinação de tabelas relacionais para analisar pedidos,
produtos, pagamentos, avaliações e vendedores do conjunto de dados Olist.

## Conceitos praticados
- LEFT JOIN e chaves de relacionamento
- COUNT e COUNT DISTINCT
- GROUP BY e HAVING
- Identificação de registros sem correspondência com IS NULL
- Análise de possíveis duplicações após múltiplos JOINs

## Aprendizados
Um JOIN pode multiplicar linhas quando existem múltiplos registros
relacionados em tabelas diferentes. Antes de agregar valores, é
importante compreender a granularidade dos dados.
